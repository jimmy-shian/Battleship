登入房間

房間（全系統固定三間，選一間進入）
回合規則

正在確認伺服器…

固定三間房：Room1／Room2／Room3，每間同時一場對戰（2 人），第三位進入會顯示「房間已滿」。戰績每間最多保留 100 筆，滿了由後端自動刪除最舊的紀錄；紀錄會顯示玩家名稱。

房間狀態

說明

  • 1. 從「房間」下拉選 Room1／Room2／Room3 其中一間，兩人選同一間就會對戰。
  • 2. 各自在「我的海域」擺好 4 艘船並鎖定。
  • 3. 輪流在「敵方海域」點擊開火，點下去就會自動標記結果，由伺服器判定。
  • 4. 擊沉的船會自動標註周圍落空，全數擊沉即結算。
單機版（可離線遊玩 / 紀錄） 戰績存檔

進階設定

本機測試可填 http://127.0.0.1:8787（先執行 npm run dev）。

遊戲規則
目標

雙方輪流猜對方船艦的位置，最先擊沉對方所有船艦的人獲勝。

船艦

5×5 海域，每人 4 艘：3 格 ×1、2 格 ×2、1 格 ×1，共 8 格。橫放或直放，不可重疊，也不可相鄰（含斜角）。

回合

由系統分配回合，點擊「敵方海域」的格子直接開火，點下去就會自動標記結果（落空 / 命中 / 擊沉）並同步給雙方。

敵方海域圖示
落空：這一格沒有船
命中：這一格有船（周圍不一定無船，只記這格）
擊沉：整艘船都命中
自動標註：擊沉後，船周圍一圈會自動變為落空
我方海域圖示
對方開火落空
我方船艦被命中的那一格
自動標註

擊沉一艘船後，其周圍一圈會自動標為落空，省去手動記憶。

手動標註

開啟「標註模式」後可自行在敵方海域記錄推測的落空 / 命中 / 擊沉，不影響系統判定結果。

結算

擊沉對方全部船艦即結束本局，顯示雙方出擊數、命中數與命中率，並可一鍵再戰。
